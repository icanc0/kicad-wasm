# M1.2 — kimath partial build (27/40 files to WASM)

Ran 2026-08-24, second POC iteration.

## Result

Compiled `27 of 40` KiCad `libs/kimath` C++ files to WebAssembly
using emscripten 6.0.8. Static archive:

```
src/kimath-build/libkimath-partial.a  406 KB
```

## What compiled

Pure geometry + basic math, none needing anything beyond the
current wx-stub (debug + log + string minimal):

  arc_chord_params, bezier_curves, circle, convert_basic_shapes_to_polygon,
  convex_hull, corner_operations, direction_45, distribute, eda_angle,
  ellipse, geometry_utils, half_line, intersection, line, nearest, oval,
  poisson_disk, roundrect, seg, shape_arc, shape_compound, shape_ellipse,
  shape_file_io, shape_nearest_points, shape, shape_rect, vector_utils

## What failed (4 files)

- `grid_geometry` — uses a specific util not yet in the stub
- `shape_collisions` — casts or template deduction issue
- `shape_line_chain` — the big one, uses more of the tree
- `shape_poly_set` — the biggest, transitively pulls in clipper2
  headers that need their own compile pass
- Plus `math/util.cpp`, `math/vector2.cpp`, `md5_hash.cpp`,
  `transform.cpp`, `trigo.cpp`, `shape_segment.cpp`,
  `shape_utils.cpp`, `transform_trs.cpp`, `vertex_set.cpp` — most
  need small stub extensions

## What was added to wx-stub

- `wx/log.h` — no-op macros for wxLog{Error,Warning,...,Trace}
- `wx/string.h` — thin wrapper over `std::string`, char-only

## Build reproducer

```
$ cd ~/not-my-projects/kicad-wasm/src/kimath-build
$ source ../../build/emsdk-env.sh
$ make -j6
```
